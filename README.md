# Personal_Expense_Tracker
A web-based Expense Tracker built using Python, Flask, PostgreSQL, HTML, CSS and Bootstrap. Manage income, expenses, transactions and monthly spending summaries.

# Expense Tracker Application
Technologies: Python, Flask, PostgreSQL, HTML, CSS, Bootstrap

## Project Overview
Developed a web-based application to manage daily income and expenses using Flask.

## Key Features
- Implemented CRUD operations to add, view, update, and delete financial transactions.
- Integrated PostgreSQL to store user details, transactions, and expense categories.
- Designed a dashboard to display total income, expenses, remaining balance, and monthly spending summaries.
